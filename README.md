🎮 Number Guessing Game & Word Counter

📌 Project Overview

This project is developed using Python as part of my Python Programming Virtual Internship at Interncircle.

It combines two applications:

1. Number Guessing Game
2. File-Based Word Counter

🚀 Features

1. Number Guessing Game

- Generates a random number between 1 and 100.
- Allows users to guess the number.
- Provides hints (Too High / Too Low).
- Tracks the number of attempts.
- Calculates scores based on attempts.

2. Word Counter

- Reads text from a file.
- Counts the total number of words.
- Analyzes the frequency of each word.
- Removes punctuation and handles uppercase/lowercase text.

🛠️ Technologies Used

- Python
- Random Module
- String Module
- Collections Module
- File Handling

⚙️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure Python is installed.
4. Open the terminal.
5. Run the following command:

python main.py

6. Select an option from the menu:

- Enter 1 for Number Guessing Game.
- Enter 2 for Word Counter.
- Enter 3 to Exit.
